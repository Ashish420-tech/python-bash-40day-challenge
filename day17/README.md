## 📚 Program Descriptions by Category

### **🟢 Basics & Fundamentals**

#### **python1.py** – Hello World
- **Purpose**: Entry point program that outputs "Hello, World!" to demonstrate basic print functionality
- **Concepts**: Basic output, print statement, string literals
- **Use Case**: Verifies Python installation and IDE setup; foundation for all output operations
- **Output**: `Hello, World!`

#### **python2.py** – Variable Assignment & Arithmetic
- **Purpose**: Demonstrates variable initialization and basic arithmetic operations (addition)
- **Concepts**: Variable declaration, type inference, arithmetic operators
- **Use Case**: Foundational for understanding data storage and manipulation
- **Output**: `Sum: 12` (5 + 7)

#### **python3.py** – Arithmetic Operations Showcase
- **Purpose**: Comprehensive demonstration of all basic arithmetic operators (addition, subtraction, multiplication, division)
- **Concepts**: Operator precedence, multiple arithmetic operations, type coercion
- **Use Case**: Understanding mathematical computations; used in calculators and financial applications
- **Sample**: `a=20, b=5` produces Add: 25, Subtract: 15, Multiplication: 100, Division: 4.0

#### **python11.py** – Unit Conversion (Kilometers to Miles)
- **Purpose**: Real-world application converting metric units to imperial units
- **Concepts**: Mathematical formula application, floating-point operations, rounding
- **Use Case**: Geographic information systems (GIS), location-based services, travel applications
- **Formula**: `miles = kilometers * 0.621371`
- **Output**: Rounded to 2 decimal places for practical accuracy

---

### **🔵 Conditional Logic & Decision Making**

#### **python14.py** – Leap Year Validator
- **Purpose**: Determines if a given year is a leap year using conditional logic
- **Concepts**: Boolean operators (AND, OR), modulo operator, complex conditions
- **Use Case**: Calendar applications, date validation, time-series data processing
- **Logic**: Year divisible by 400 OR (divisible by 4 AND not by 100)
- **Real-world Impact**: Critical for accurate date calculations in scheduling systems

#### **python24.py** – Armstrong Number Detector
- **Purpose**: Validates whether a number is an Armstrong number (narcissistic number)
- **Concepts**: Number theory, string manipulation, list comprehension, power operations
- **Use Case**: Mathematical puzzles, cryptography, number validation in gaming
- **Definition**: Number equal to the sum of its own digits each raised to the power of the number of digits
- **Example**: 153 is Armstrong (1³ + 5³ + 3³ = 153)

---

### **🟠 Data Analysis & Validation**

#### **python59.py** – Array Monotonicity Checker
- **Purpose**: Determines if an array is monotonically increasing or decreasing
- **Concepts**: List comparison, `all()` function, generator expressions, boolean logic
- **Use Case**: Time-series data validation, trend analysis, data quality checks
- **Algorithm**: Efficiently checks if elements maintain consistent order in O(n) time
- **Application**: Stock market data validation, sensor data analysis

---

### **🟣 Algorithm Implementation**

#### **python71.py** – Binary Search Algorithm
- **Purpose**: Implements the efficient binary search algorithm on sorted arrays
- **Concepts**: Divide-and-conquer, algorithm optimization, pointer manipulation
- **Use Case**: Search operations in large datasets, database indexing, autocomplete systems
- **Time Complexity**: O(log n) - significantly faster than linear search
- **Real-world**: Powers search features in databases, file systems, and search engines
- **Note**: Requires pre-sorted array for correct functionality

---

### **🟢 Security & Validation**

#### **python96.py** – Password Strength Validator
- **Purpose**: Validates password security by checking for multiple character types
- **Concepts**: String methods (isupper, isdigit, isalnum), boolean operations, security principles
- **Use Case**: User registration systems, password policy enforcement, account security
- **Requirements Checked**:
  - Uppercase letters present
  - Numeric digits included
  - Special symbols included
- **Application**: Web application security, cybersecurity compliance
- **Security Impact**: Enforces strong password policies to prevent unauthorized access
